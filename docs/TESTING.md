# 测试与验收

## 测试框架和目录

项目使用 Python 标准库 `unittest`，测试位于 `tests/`：

- `test_analysis.py`：分位算法、固定股票完整分析、行情缺失降级、腾讯日内与分钟数据解析、
  参考指数和缓存、震荡区间与筹码估算、行业/概念/主营边界，以及单标的/大盘 AI 事实
  目录与开放式提示词；
- `test_http.py`：在随机本机端口启动真实 `Handler`，Mock 业务/模型层后验证页面、
  自选分组契约和 API，包括 `/api/intraday`、`/api/key-levels` 与按需单标的
  `/api/security_report`；
- `test_industry_flow.py`：同花顺行业净额解析和主源优先、东方财富完整榜回退、历史资金流、
  快照优先/后台刷新、更新失败保留以及 `market_overview()` 的来源与排序契约；
- `fixtures.py`：固定 K 线、估值和标的元数据。
- `test_monitoring_db.py`：SQLite 重启持久化与分层清理；
- `test_monitoring_rules.py`：连续确认、回差、重新武装和上下穿；
- `test_monitoring_service.py`：零 Token 轮询、去重、每日快照复用和中国交易时段；
- `test_monitoring_assistant.py`：AI 草案白名单和 7 天缓存。
- `test_monitoring_explanations.py`：事件复核严格 JSON、7 天缓存、去重和用量回滚；
- `test_monitoring_presets.py`：三线价格校验、自动异动、预设替换隔离和简洁总览。
- `test_monitoring_web.py`：Web 后台线程启停、0 Token 状态、通知凭据脱敏和无副作用
  模拟提醒。
- `test_holding_ocr.py`：图片与 Base URL 校验、千问请求格式、结果清洗、错误脱敏和
  7 天缓存；不调用真实百炼。
- `test_portfolio.py`：组合汇总、用户判断先锁定、首轮输入隔离、二轮观点对比、
  DeepSeek/GPT 请求契约、Flash/Pro 缓存隔离、两次额度预留、失败用量、7 天缓存和
  最近 7 次历史；
- `test_portfolio_analysis.py`：静态组合曲线、期初市值贡献、共同截止日、数据质量门控、
  集中度/相关性覆盖、四类强弱状态和无前视历史诊断重放。

```powershell
python -X utf8 -m unittest discover -s tests -v
python -m compileall -q app.py agent.py monitor.py monitoring tests
```

```powershell
python -m pip install -r requirements.txt
```

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_experience_package.ps1
```

测试和开发文档。交付前还应把 ZIP 解压到独立目录，检查 Python 文件可编译、三个入口模块
可导入，并在未安装项目依赖的普通 Windows 电脑上人工验证首次安装与 `启动.bat`。

## Mock 边界

- 测试不访问同花顺、东方财富、腾讯、新浪、Baostock 或任何模型 API；行业快照固定重定向至临时文件。
- 完整分析测试替换代码识别、K 线、估值、资金流和财务数据函数，但执行真实
  `analyze`、指标计算、报告、风险和响应清洗。
- HTTP 测试执行真实 `ThreadingHTTPServer` 和 `Handler`，只替换耗时业务函数。
- 随机端口避免依赖或干扰生产端口 `8688`。

- 行业资金流覆盖同花顺多页表格、净额与既有 `main_net` 语义隔离、主源优先/东财回退、

- 不完整行业快照不得携带主力净流入字段进入单标的 AI 事实目录；
- `/api/key-levels` 只有点击后才调用，非法代码在取数前拒绝，首页包含加载/隐藏入口；
- 东方财富 F10 固定样例的三级行业、最多 4 个概念、主营摘要与地域板块排除；
- 单标的 AI 只收到连续编号的原始事实，不收到规则报告、风险理由或提醒结论；
- 单标的与大盘提示词不预设固定分析栏目，模型可自行选择重点和组织顺序；
- 模型引用不存在的事实编号时服务端拒绝结果，只返回本次实际引用的事实；
- 外部 K 线缺失时返回受控错误；
- 首页 HTML、当前 SVG/自选标记和旧 canvas 排除；
- 自选分组输入、改单只分组、整组重命名/合并、当天轨迹、组内聚合和回暖状态的
  前端契约；
- 有效/无效查询接口、无 Key 错误和未知路由。
- 项目本地 HTTP 服务独占监听端口，第二个实例不能复用同一地址。
- 盯盘数据库、7 天分钟清理、每日快照长期保留和跨重启配置；
- 规则确认/回差去重、分析刷新复用、分钟循环 0 Token；
- 三线预设重复设置不删除手工高级规则、持仓成本或备注；
- Web 监控 API 的保存、读取、删除、运行操作和无正式数据库污染；
- 风险提醒模拟复用真实提醒格式，且不写事件、不创建后台服务、不发通知、不消耗
  Token；
- AI 草案缓存命中后不重复调用模型，最多 3 条、严格 JSON、保留待确认项且不自动
  创建规则。
- 逻辑卡可先于三线保存，AI 转化不自动创建规则；
- 事件复核相同输入不重复调用模型，失败解析释放预留额度；
- 本地交易日历可覆盖普通工作日/周末判断；
- 外部通知失败按渠道入队，成功重试后更新事件状态。
- 持仓批量写入原子校验、原有规则/备注/启停状态保留，以及缺失旧持仓不自动删除；
- 千问截图输入限制、阿里云域名白名单、严格 JSON/数值/重复代码校验、模糊字段校对
  标记、7 天缓存，以及原图、Key 和 Base URL 不落库。
- 持仓报告首轮请求不包含用户判断，二轮才读取；相同模型、快照和判断不重复调用模型，
  锁定原文与报告状态跨刷新保留，DeepSeek Key 不出现在响应；成功报告仅保留并列出
  最近 7 次，失败模型响应按可得真实 Token 记账。
- 第一阶段只接受程序事实目录中的 `evidence_id`；未知 ID 被拒绝，通过的 ID 由服务端
  还原为确定性事实文字，模型不能自由写入“已确认事实”；
- 组合曲线和 5/10/20/60 日贡献可对账；聚合指标统一到共同截止日，缺少完整窗口、
  近期长缺口或末端陈旧时降级为“数据不足”；
- 行业/主题/高波动和相关性结论受有效权重或配对覆盖门控，高相关连通组权重可复现；
- 历史诊断只在观察日及以前形成状态，并要求完整的随后 10 日观察窗口；当前持仓不完整
  时不能把可分析子集写成完整组合重放；
- DeepSeek 只接受 Flash/Pro 且模型选择进入持仓报告、规则草案和事件复核缓存；DeepSeek
  与 GPT 分别锁定 `/chat/completions` 和 Responses API 请求契约；两阶段额度
  在首轮前原子预留，任一阶段失败后按实际已返回调用和 Token 结算；
- 多日市场背景的坏历史显示“数据不足”且不参与排名；集中度重点问题标明实际触发来源。

1. 确认监听地址为 `127.0.0.1:8688`，且页面来自当前磁盘 `app.HTML`。
