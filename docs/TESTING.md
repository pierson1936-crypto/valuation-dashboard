# 测试与验收

## 测试框架和目录

项目使用 Python 标准库 `unittest`，测试位于 `tests/`：

- `test_analysis.py`：分位算法、固定股票完整分析、行情缺失降级；
- `test_http.py`：在随机本机端口启动真实 `Handler`，Mock 业务/模型层后验证页面、
  自选分组契约和 API；
- `fixtures.py`：固定 K 线、估值和标的元数据。
- `test_monitoring_db.py`：SQLite 重启持久化与分层清理；
- `test_monitoring_rules.py`：连续确认、回差、重新武装和上下穿；
- `test_monitoring_service.py`：零 Token 轮询、去重、每日快照复用和中国交易时段；
- `test_monitoring_assistant.py`：AI 草案白名单和 7 天缓存。
- `test_monitoring_explanations.py`：事件复核严格 JSON、7 天缓存、去重和用量回滚；
- `test_monitoring_presets.py`：三线价格校验、自动异动、预设替换隔离和简洁总览。
- `test_monitoring_web.py`：Web 后台线程启停、0 Token 状态、通知凭据脱敏和无副作用
  模拟提醒。

## 命令

```powershell
python -X utf8 -m unittest discover -s tests -v
python -m compileall -q app.py agent.py monitor.py monitoring tests
```

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

## Mock 边界

- 测试不访问东方财富、腾讯、新浪或任何模型 API。
- 完整分析测试替换代码识别、K 线、估值、资金流和财务数据函数，但执行真实
  `analyze`、指标计算、报告、风险和响应清洗。
- HTTP 测试执行真实 `ThreadingHTTPServer` 和 `Handler`，只替换耗时业务函数。
- 随机端口避免依赖或干扰生产端口 `8688`。

## 当前覆盖

- 项目和核心模块可导入/编译；
- 分位的相等值中位秩、`None` 和负值现有行为；
- 固定股票样例的 PE、PB、价格分位和核心输出键；
- 外部 K 线缺失时返回受控错误；
- 首页 HTML、当前 SVG/自选标记和旧 canvas 排除；
- 自选分组输入、改单只分组、整组重命名/合并、当天轨迹、组内聚合和回暖状态的
  前端契约；
- 有效/无效查询接口、无 Key 错误和未知路由。
- 盯盘数据库、7 天分钟清理、每日快照长期保留和跨重启配置；
- 规则确认/回差去重、分析刷新复用、分钟循环 0 Token；
- 三线预设重复设置不删除手工高级规则、持仓成本或备注；
- Web 监控 API 的保存、读取、删除、运行操作和无正式数据库污染；
- 风险提醒模拟复用真实提醒格式，且不写事件、不创建后台服务、不发通知、不消耗
  Token；
- AI 草案缓存命中后不重复调用模型，最多 3 条、严格 JSON、保留待确认项且不自动
  创建规则。
- 逻辑卡可先于三线保存，AI 转化不自动创建规则；
- 事件复核相同输入不重复调用模型，失败解析释放预留额度；
- 本地交易日历可覆盖普通工作日/周末判断；
- 外部通知失败按渠道入队，成功重试后更新事件状态。

## 运行时验收

推荐启动：

```powershell
python -X utf8 app.py
```

验收清单：

1. 确认监听地址为 `127.0.0.1:8688`，且页面来自当前磁盘 `app.HTML`。
2. 浏览器打开大盘、个股分析、自选和多股对比标签。
3. 桌面与移动宽度下确认无重叠、文本清晰、SVG 非空。
4. 固定或真实样例查询后，核对 `code/name/date/count/price/price_pct`；
   股票还需核对 `pe/pb/pe_pct/pb_pct`。
5. 不使用真实 Key 验收 AI；只验证缺 Key 时受控报错。需要真实模型回归时由用户
   在本机设置环境变量，测试不得记录 Key。

- 免费外部接口的实时可达性、限流和字段漂移；
- Excel 工作簿内容和图表的逐单元格断言；
- DeepSeek/OpenAI/Anthropic 的真实鉴权、费用和模型兼容；
- 大规模并发、缓存竞争、慢请求和服务关闭；
- 全部浏览器交互和响应式布局；
- TLS 恢复后的上游兼容性。

核心业务改动必须至少更新固定样例断言；接口字段变更必须同时更新 HTTP 测试、
README、ARCHITECTURE 和 FILE_MAP，并取得用户确认。
