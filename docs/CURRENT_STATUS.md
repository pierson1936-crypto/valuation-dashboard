- 本地 Web 分析台、单标的查询、大盘、自选分组追踪、Excel 导出；
- 可选 DeepSeek AI 助手、大盘解释、多股对比和可选 GPT 首席；多维分析页面入口已下线，
  旧后端接口暂作兼容保留；
- 单标的“分析报告”新增按需 DeepSeek 独立分析：模型读取编号事实目录后自行选择重点、
  顺序和表达，后台只校验引用编号；原规则报告折叠保留为零 Token 数据底稿；
- AI 大盘报告改为开放式复盘：模型自行识别指数/板块结构和矛盾，不使用固定栏目模板，
  同样要求引用编号事实；
- 本地 SQLite 自选盯盘、确定性规则、事件记录、企微/Server酱通知适配；
- 三线快速设置：关注价、风险价、可选目标价和自动 `±3%` 异动；
- Web 盯盘标签：三线设置、启停、运行状态、数据计数和最近提醒；
- 按需 AI 规则草案，结果缓存且不自动启用；
- 自选页内的持仓截图导入：千问视觉识别、人工校对和本地持仓写入；
- 持仓页可先执行 0 Token 组合扫描，再按需选择 DeepSeek 或 GPT 生成两阶段报告；
  GPT 默认 `gpt-5.6-sol`，最近 7 次成功分析可切换复盘；
- GPT 持仓报告已改用 Responses API 的严格 JSON Schema 输出，分别锁定独立分析和
  用户判断对照的既有字段；保留原有本地校验。HTTP 400 会显示 OpenAI 的具体错误信息。
  未用真实 OpenAI Key 验证，仍待一次用户主动发起的实际调用确认。
- 右下角 AI 助手支持可选 PNG/JPG 图片附件，也可直接在聊天输入框粘贴截图：带图问题先
  复用持仓截图识别已保存的千问 Key/Base URL 生成自由格式的图片观察记录，再交由 DeepSeek
  解读；原图和千问识别结果均不写入数据库，原图也不会在后续对话中重复发送。无图聊天仍只
  调用 DeepSeek。
- ETF 的 `/api/analyze` 新增公开跟踪标的、最近报告期行业配置、前十大持仓和权重；
  单标的页面已显示“ETF 定位与指数追踪”。它不改变估值、技术、风险或盯盘口径；
- 单标的页面新增“今日分时 · 相对强弱”：股票与所属市场参考指数比较，ETF 优先使用公开
  跟踪指数，匹配不到时回退沪深 300；图中显示标的、参考指数、标的均价和成交量；
- 分时独立于主分析加载，暂时失败不会清空或阻塞其他分析。成功缓存 60 秒，失败缓存 15 秒；
- K 线新增“加载关键位”：默认不请求，点击后保守识别近期震荡区间；普通股票另用东方财富
  前复权日 K 和换手率估算成本区、主要筹码峰与筹码分布，ETF 第一版只识别震荡区间；
- 关键位只用于图表观察，不进入风险评分、AI、盯盘或买卖建议。筹码是本地算法估算，
  不是东方财富直接返回的筹码成品数据或真实账户持仓；
