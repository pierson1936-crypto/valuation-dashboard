估值分析台 - 快速开始
=====================

一、运行条件

1. Windows 10 或 Windows 11。
2. 已安装 Python 3.10 或更高版本。
3. 电脑可以联网。首次运行需要安装项目组件；行情、公开资料和图表也需要网络。

二、启动

1. 先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击“启动.bat”。
3. 首次运行会自动安装所需组件，请等待安装完成。
4. 浏览器会打开 http://127.0.0.1:8688/ 。如果没有自动打开，可手动访问该地址。
5. 使用结束后，关闭启动窗口即可停止服务。

三、功能与数据

- 基础行情、估值、技术分析、自选和本地盯盘无需 AI Key。
- AI 功能为可选项，请只在自己的电脑上配置自己的 Key，不要把 Key 发给他人。
- 自选和部分界面偏好保存在浏览器中；盯盘与持仓状态保存在本机 data 目录中。
- 行情和图表依赖公开数据源与 CDN，网络波动时可能暂时无法加载，可稍后重试。

四、其他入口

- “启动AI助手.bat”：命令行 AI 助手，需要 DeepSeek API Key。
- “启动盯盘.bat”：独立运行本地盯盘循环，按 Ctrl+C 停止。

五、常见问题

- 提示找不到 Python：安装 Python 3.10+，并在安装界面勾选 Add Python to PATH。
- 提示组件安装失败：检查网络后重新双击“启动.bat”。
- 提示端口 8688 被占用：关闭此前打开的另一份估值分析台，再重新启动。
- 页面能打开但图表或行情为空：先检查网络，稍后重新查询。

本工具仅供学习研究，不构成任何投资建议。
